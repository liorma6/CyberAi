## שני הבודקים

1. הורידו את ה־ZIP האישי, חלצו את כל הקבצים לאותה תיקייה ופתחו את `index.html` בדפדפן. אפשר לעבוד ללא התקנה. במחשב שכבר מריץ את הממשק אפשר לפתוח את הטופס גם מעמוד הצוות. בחרו דרך אחת והמשיכו בה כדי לשמור את הטיוטה באותו דפדפן.
2. התחילו ב־F01. קראו את שורות המקור ואת שני התדריכים באנגלית, A ו־B. אפשר לפתוח הפניות ללוג כדי לבדוק טענה. כל בודק מקבל סדר תיקים ושיוך A/B משלו. עבדו עצמאית עד למסירת הטפסים. הרכז מחזיק אצלו את מפתח הזיהוי ואת דוח התוצאות.
3. לכל תדריך בנפרד בחרו שני ציונים לפי הטבלה. הוסיפו הערה קצרה על פרט שהשפיע עליכם. מותר לתת ציונים זהים. לדוגמה, אפשר להסביר בהערה איזה פרט חסר צריך לבדוק כדי להבדיל בין שתי השערות. אם תדריך אינו זמין, הציונים לפי הפרוטוקול הם 0 ו־1.
4. עברו על כל 20 התיקים. בתום 40 תדריכים מדורגים לחצו על **הורדת CSV למסירה**. החזירו את הקובץ לרכז עם שם התפקיד שלו.

## שחזור עצמאי במחשב של חבר צוות

דרושים Git, חיבור אינטרנט ו־Python 3.13 או 3.14. השחזור מאמת את מדדי הגלאים ואת הבדיקות האוטומטיות מתוך עותק חדש. ציוד ה־GPU המקומי שימש למדידות החומרה המתועדות. השחזור הזה פועל גם במחשב עם CPU בלבד.

פתחו PowerShell בתיקייה שנוח ליצור בה עותק חדש והדביקו את הקטע במלואו.

```powershell
$copy = "EvidenceSOC-clean-" + (Get-Date -Format "yyyyMMdd-HHmmss")
git clone https://github.com/liorma6/CyberAi.git $copy
if ($LASTEXITCODE -eq 0) {
    Set-Location (Join-Path $copy "Projects/EvidenceSOC")
    python reproduce_stage7.py
}
```

אם הפקודה `python` מפעילה גרסה אחרת, אפשר להריץ מאותה תיקיית פרויקט `py -3.13 reproduce_stage7.py` או `py -3.14 reproduce_stage7.py` לפי הגרסה המותקנת. הסקריפט יוצר סביבה נפרדת, מתקין את התלויות הנעולות ומריץ את הבדיקות, כולל יצירה מחדש של שלושת מערכי הניסוי והשוואה לנתונים שפורסמו.

הנתיב ללוג מודפס בתחילת ההרצה. בסיום החזירו לרכז את קובץ ה־TXT מתיקיית `runs/stage7-reproduction` וציינו מי הריץ. הקובץ כולל את הקומיט, סביבת ההרצה, הפקודות והתוצאות. במקרה של `FAIL` מחזירים את הלוג עם השגיאה, מתקנים ומריצים שוב.
