השלמת שלב 7

רכז הקבוצה אוסף שלושה קבצים: שני גיליונות דירוג ולוג הרצה אחד. בחרו לכל משתתף תפקיד לפני שפותחים טופס.

בודקים 1 ו־2 · הערכה עצמאית

  1. כל בודק פותח רק את הטופס שהוקצה לו. במחשב אחר מורידים את ה־ZIP המתאים, מחלצים את כל הקבצים ופותחים את index.html. הטופס פועל גם בלי התקנה.
  2. בכל אחד מ־20 התיקים קוראים את תדריך A ואת תדריך B באנגלית. לחיצה על הפניה מציגה את שורת הלוג. אפשר לקרוא גם את ציר הזמן.
  3. לכל תדריך בוחרים שני ציונים: עד כמה הוא מזהה מידע שחסר לחקירה (0–2), ועד כמה הוא עוזר להחליט מה לבדוק עכשיו (1–5). בטופס מופיע פירוש לכל ציון. מוסיפים הערה קצרה על מה שהשפיע על הדירוג. מותר לתת תיקו.
  4. כשהמונה מגיע ל־40 מתוך 40, לוחצים על הורדת CSV למסירה. שומרים את הקובץ ושולחים אותו לרכז. עד ששני הבודקים מסיימים, עובדים בנפרד ושומרים את דוח התוצאות ומפתח הזיהוי אצל הרכז.

חבר הצוות השלישי · שחזור מעותק נקי

מריצים במחשב של חבר צוות אחר, עם Git ו־Python 3.13 או 3.14. פתחו PowerShell בתיקייה שבה מותר ליצור עותק חדש, והדביקו את הפקודות האלה. ההרצה מתקינה את התלויות בסביבה נפרדת. נדרש אינטרנט להורדת הקוד והתלויות. אין צורך בכרטיס מסך, ב־Docker או ב־Ollama לבדיקת השחזור הזאת.

$copy = "EvidenceSOC-clean-" + (Get-Date -Format "yyyyMMdd-HHmmss")
git clone https://github.com/liorma6/CyberAi.git $copy
if ($LASTEXITCODE -eq 0) {
    Set-Location (Join-Path $copy "Projects/EvidenceSOC")
    python reproduce_stage7.py
}

הסקריפט רושם את הקומיט, מערכת ההפעלה, גרסת Python, הפקודות והתוצאות. הוא מריץ את הבדיקות, כולל יצירה מחדש של שלושת מערכי הניסוי והשוואה לתוצאות שפורסמו. חפשו PASS או FAIL בשורה האחרונה. החזירו לרכז את reproduction-….txt מתוך runs/stage7-reproduction וציינו מי הריץ. גם במקרה של כשל, שמרו את הלוג כדי שנוכל לאבחן אותו.

רכז הקבוצה · מסירה

צרפו לצ׳אט הזה את R1-ratings.csv, את R2-ratings.csv ואת לוג השחזור. אחרי שנקבל אותם נוכל לאמת שלמות, לחשב ציונים ופערים בין הבודקים, ולהוסיף את תוצאת השחזור לדוח. שלב 7 נסגר אחרי שני דירוגים מלאים ושחזור שעבר.
